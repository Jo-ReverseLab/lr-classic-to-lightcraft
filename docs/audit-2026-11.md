## Performance

`--apply` of 752 photos with real files (LightCraft 0.21.1, Apple M4 Pro):

| | Before | After |
| --- | --- | --- |
| Whole run | 111 s | 47 s |
| Commands sent | 5,187 | 4,447 |
| Time inside LightCraft | 74 s | 42 s |
| `library.import` | 752 single, 36 s | 12 batches, 4.6 s |
| Outside LightCraft (mostly saving the mapping file) | 37 s | 5 s |

Changes: imports in batches of 64 from 100 photos on; the mapping file is
saved at once only for records a later run cannot find again, otherwise at
most once a second and on every exit. All 752 LightCraft ids were checked
against their file names. Still open: 1,270 `library.select` commands
(about 10 s) could be saved (see #45 and the notes for the next step).

A run of the small test catalog (8 photos, 138 commands) takes 1.3 s. One
entry per photo, field, keyword and album is by design, so a catalog has
many more log entries than photos; the report and the window now count
photos separately (`photo_counts`).
