# Fonts

`Inter-Regular.ttf`, `Inter-Medium.ttf` and `Inter-SemiBold.ttf` are the
static TrueType fonts of Inter 4.1 by The Inter Project Authors
(https://github.com/rsms/inter, release `v4.1`, files `extras/ttf/`),
unchanged. They are licensed under the SIL Open Font License 1.1; the
license text is in `OFL.txt`.
